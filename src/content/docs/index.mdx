## What is Forge?

Forge is a single Rust binary that gives every coding-agent task a real lifecycle:
`todo → in_progress → review → merging → done`. Each task gets its own isolated git
worktree, a configurable CI review gate, and an audit log. You drive it through a REST
API, an MCP endpoint, the `forge-ctl` CLI, or the built-in web UI — all served from
`127.0.0.1:8080`.

<CardGrid stagger>
  <Card title="Plug into your agent" icon="puzzle">

  </Card>
  <Card title="Isolated worktrees" icon="seti:folder">

  </Card>
  <Card title="CI review gates" icon="approve-check">

    Combine with auditor-style checks for human-in-the-loop.
  </Card>
  <Card title="Self-hosted, MIT" icon="laptop">
    Run Forge in your own environment. SQLite + WAL, no accounts, no telemetry,
    no SaaS — your code never leaves your infrastructure.
  </Card>
